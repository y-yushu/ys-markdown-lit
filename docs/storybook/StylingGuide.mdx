# 样式定制指南

`<ys-md-rendering>` 使用 Shadow DOM 封装内部样式。外部定制时，建议按以下分层选择机制，**从标准、可维护的方式开始，最后再使用兜底方案**。

---

**原则：**

- 改整站主色、链接色、引用背景 → 优先 **CSS 变量**，不要给每个元素写一条 `::part()`
- 表格行 hover、链接 hover → 用 **`::part():hover`**
- 长 CSS 字符串塞进 HTML 属性 → 尽量避免，改用外部 `.css` 文件

## 1. CSS 变量（主题 Token）

组件支持通过公开 CSS 变量 `--ys-md-*` 覆盖样式。通常把变量写在 `<ys-md-rendering>` 宿主元素上；如果只想影响内部 Markdown 根容器，也可以写在 `::part(container)` 上。

```css
/* global.css */
ys-md-rendering {
  --ys-md-link: #00aa00;
  --ys-md-h1-size: 2em;
}
```

也可写在容器 part 上：

```css
ys-md-rendering::part(container) {
  --ys-md-link: #00aa00;
}
```

### 支持的 Token（公开名）

以下是当前组件支持外部设置的公开变量。

#### 布局与基础颜色

| 变量 | 用途 |
| --- | --- |
| `--ys-md-content-width` | Markdown 根容器最大宽度；默认填满外层容器 |
| `--ys-md-container-padding` | Markdown 根容器内边距；默认不增加左右留白 |
| `--ys-md-bg` | Markdown 根容器背景 |
| `--ys-md-text` | 正文与主要文字颜色 |
| `--ys-md-muted` | 次要文字颜色，影响小标题、颜色标记等 |
| `--ys-md-link` | 链接颜色 |
| `--ys-md-border` | 通用边框颜色 |
| `--ys-md-soft-bg` | 行内代码、kbd、部分弱背景 |
| `--ys-md-selection` | 文本选中背景 |

#### 字体与段落节奏

| 变量 | 用途 |
| --- | --- |
| `--ys-md-line-height` | Markdown 根容器行高 |
| `--ys-md-heading-weight` | 标题字重 |
| `--ys-md-strong-weight` | 加粗文本与定义标题字重 |
| `--ys-md-heading-margin` | 标题外边距 |
| `--ys-md-heading-padding-block-end` | h1 / h2 底部内边距 |

| `--ys-md-h1-size` | h1 字号 |
| `--ys-md-h2-size` | h2 字号 |
| `--ys-md-h3-size` | h3 字号 |
| `--ys-md-h4-size` | h4 字号 |
| `--ys-md-small-heading-size` | h5 / h6 字号 |
| `--ys-md-block-margin` | 段落、列表、引用、代码块、表格等块级元素外边距 |
| `--ys-md-hr-margin` | 分割线外边距 |
| `--ys-md-img-margin` | 图片外边距 |
| `--ys-md-dd-margin-left` | 定义列表 dd 左边距 |

| 变量 | 用途 |

| 变量 | 用途 |
| --- | --- |

| `--ys-md-blockquote-border-color` | 引用块边框颜色 |
| `--ys-md-blockquote-border-width` | 引用块左侧边框宽度 |

| `--ys-md-blockquote-shadow` | 引用块阴影 |
| `--ys-md-blockquote-inner-gap` | 引用块内部连续段落间距 |

#### 代码

| 变量 | 用途 |
| --- | --- |
| `--ys-md-code-bg` | 代码块背景 |
| `--ys-md-code-text` | 代码块文字颜色 |
| `--ys-md-code-padding` | 代码块内容内边距 |
| `--ys-md-code-font-size` | 代码块字号 |

#### 标记

| 变量 | 用途 |
| --- | --- |
| `--ys-md-mark-bg` | `==mark==` 高亮背景 |

### `size` 派生尺寸

`size` 属性会在组件内部容器上动态注入一组派生尺寸变量，例如 `--rem-size`、`--ys-md-unit`、`--ys-md-space-*`、`--ys-md-radius-*`、`--ys-md-scrollbar-size`。

这些变量用于组件内部排版计算，不作为推荐的外部覆盖 API。需要整体缩放时，优先使用 `size`：

```html
<ys-md-rendering size="18" content="..."></ys-md-rendering>
```

需要精细调整某类节点时，优先使用语义化 CSS 变量或 `::part()`，例如：

```css
ys-md-rendering {
  --ys-md-list-padding: 1.25em;
  --ys-md-code-block-radius: 8px;
}

ys-md-rendering::part(code-block-header) {
  min-height: 2.25em;
}
```

## 2. `::part()` 外部样式

Shadow 内主要节点已暴露 `part`，可从外部写标准 CSS，**支持 `:hover`、`:focus`、`:active`**：

```css
/* 链接 hover */
ys-md-rendering::part(link):hover {
  text-decoration: underline;
  opacity: 0.85;
}

/* 表格行 hover */
ys-md-rendering::part(table-row):hover {
  background: rgba(15, 91, 216, 0.08);
}

/* 引用块 */
ys-md-rendering::part(blockquote) {
  border-left-color: var(--ys-md-link);
}

/* Task List */
ys-md-rendering::part(task-checkbox) {
  accent-color: #0f5bd8;
}

ys-md-rendering::part(task-list-item) {
  margin-block: 0.25em;
}
```

Task List 只会在列表项开头识别 <code>[x]</code>、<code>[X]</code>、<code>[ ]</code>、<code>[]</code>。纯 Task List 的父级列表会额外暴露 <code>task-list</code>，用于单独控制缩进；混合普通列表项时，父级仍按普通列表处理。

```css
ys-md-rendering::part(task-list) {
  padding-left: 0;
}

ys-md-rendering::part(task-checkbox-checked) {
  accent-color: #16a34a;
}

ys-md-rendering::part(task-checkbox-unchecked) {
  accent-color: #94a3b8;
}
```

**限制：**

- 只能 styling **挂了 `part` 的元素本身**，不能写 `::part(table) td` 这类子选择器
- 插件子组件（如 `ys-code-highlight`）在各自 Shadow Root 内，需使用插件自身的 `part`（如有）

## 3. `custom-css`（兜底）

向 Shadow Root 注入一段完整 CSS 文本：

```html
<ys-md-rendering custom-css=".ys-md-tr:hover { background: rgba(0,0,0,.04); }" />
```

建议在框架中通过 **property 绑定**（`.customCss="..."`）传入，避免在 HTML attribute 上写长字符串。

**仅建议在以下情况使用：**

- Shadow 内暂无对应 `part` 的选择器
- 临时调试

日常主题与交互态定制，应优先使用 **CSS 变量 + `::part()`**。

## 示例：组合使用

```css
/* app.css — 品牌 token */
ys-md-rendering {
  --ys-md-link: #0f5bd8;
  --ys-md-soft-bg: #f3f7fd;
}

/* 交互态 */
ys-md-rendering::part(link):hover {
  text-decoration: underline;
}

ys-md-rendering::part(table-row):hover {
  background: rgba(15, 91, 216, 0.06);
}
```

```vue
<ys-md-rendering density="streaming" appearance="blue" mode="light" :size="16" :content="markdown" />
```

无需再传入大段 `custom-css`，除非有 Shadow 内部的特殊需求。
