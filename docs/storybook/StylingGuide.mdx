# 样式定制指南

`<ys-md-rendering>` 使用 Shadow DOM 封装内部样式。外部定制时，建议按以下分层选择机制，**从标准、可维护的方式开始，最后再使用兜底方案**。

---

**原则：**

- 改整站主色、链接色、引用背景 → 优先 **CSS 变量**，不要给每个元素写一条 `::part()`
- 表格行 hover、链接 hover → 用 **`::part():hover`**
- 接口返回「某段引用要红色边框」→ 用 **`custom-styles`**
- 长 CSS 字符串塞进 HTML 属性 → 尽量避免，改用外部 `.css` 文件

## 0. 基线：`density` / `appearance` / `mode` / `size`

```html

  appearance="blue"
  mode="light"

  content="..."
></ys-md-rendering>
```

## 1. CSS 变量（主题 Token）

组件通过 **双层 token** 控制样式：

<table>
  <thead>
    <tr>
      <th>层级</th>
      <th>命名</th>
      <th>谁赋值</th>
      <th>用途</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>公开</td>
      <td>
        <code>--ys-md-link</code>、<code>--ys-md-h1-size</code> 等
      </td>
      <td>宿主 / <code>::part(container)</code> / <code>size</code> 属性</td>
      <td>业务覆盖入口，优先级最高</td>
    </tr>
    <tr>
      <td>预设</td>
      <td>
        <code>--ys-md-preset-link</code> 等
      </td>
      <td>
        <code>density</code> / <code>appearance</code> 主题文件
      </td>
      <td>主题默认值；无公开覆盖时生效</td>
    </tr>
  </tbody>
</table>

结构层消费模式：`var(--ys-md-link, var(--ys-md-preset-link))` — 先读公开变量，未设置则用 preset。

在**业务项目的样式表**中设置公开 token 即可覆盖主题：

```css
/* global.css */
ys-md-rendering {
  --ys-md-link: #00aa00;
  --ys-md-h1-size: 2em;
}
```

也可写在容器 part 上：

```css
ys-md-rendering::part(container) {
  --ys-md-link: #00aa00;
}
```

各 `density` / `appearance` 预设通过 `--ys-md-preset-*` 赋值；**公开** `--ys-md-*` 在宿主或 `::part(container)` 上设置时，会覆盖对应 preset。

## 2. `::part()` 外部样式

Shadow 内主要节点已暴露 `part`，可从外部写标准 CSS，**支持 `:hover`、`:focus`、`:active`**：

```css
/* 链接 hover */
ys-md-rendering::part(link):hover {
  text-decoration: underline;
  opacity: 0.85;
}

/* 表格行 hover */
ys-md-rendering::part(table-row):hover {
  background: rgba(15, 91, 216, 0.08);
}

/* 引用块 */
ys-md-rendering::part(blockquote) {
  border-left-color: var(--ys-md-link);
}
```

## 3. `custom-styles`（运行时 inline）

`custom-styles` 是一个 JSON 对象，按 **HTML 标签名** 为对应节点生成 **inline `style`**：

```html
<ys-md-rendering
  .customStyles=${{
    blockquote: { borderLeftColor: '#0f5bd8', padding: '1em' },
    a: { fontWeight: '600' },
  }}
  content="..."
></ys-md-rendering>
```

Vue 示例：

```vue
<ys-md-rendering
  :custom-styles="{
    blockquote: { borderLeftColor: '#0f5bd8' }
  }"
  :content="content"
/>
```

支持的 key 与渲染器一致，例如：`h1`~`h6`、`p`、`blockquote`、`a`、`ul`、`ol`、`li`、`table`、`tr`、`th`、`td`、`strong`、`em`、`code`、`img` 等。

**适用：** 后端 / 配置驱动的单节点样式。

**不适用：**

- `:hover`、媒体查询、伪元素（请用 `::part()` 或 CSS 变量）
- 整站主题（请用 CSS 变量）

---

## 4. `custom-css`（兜底）

向 Shadow Root 注入一段完整 CSS 文本：

```html
<ys-md-rendering custom-css=".ys-md-tr:hover { background: rgba(0,0,0,.04); }" />
```

建议在框架中通过 **property 绑定**（`.customCss="..."`）传入，避免在 HTML attribute 上写长字符串。

**仅建议在以下情况使用：**

- Shadow 内暂无对应 `part` 的选择器
- 临时调试

日常主题与交互态定制，应优先使用 **CSS 变量 + `::part()`**。

## 示例：组合使用

```css
/* app.css — 品牌 token */
ys-md-rendering {
  --ys-md-link: #0f5bd8;
  --ys-md-soft-bg: #f3f7fd;
}

/* 交互态 */
ys-md-rendering::part(link):hover {
  text-decoration: underline;
}

ys-md-rendering::part(table-row):hover {
  background: rgba(15, 91, 216, 0.06);
}
```

```vue
<ys-md-rendering density="streaming" appearance="blue" mode="light" :size="16" :content="markdown" />
```

无需再传入大段 `custom-css`，除非有 Shadow 内部的特殊需求。
